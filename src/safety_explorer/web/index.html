Why blinded

If the annotator can see that a response came from the variant labelled "explicitly harmful", they will score it as degraded, and the instrument measures the annotator's expectations rather than the model's behaviour. Metadata is revealed only after the rating is submitted, and the reveal is logged. Unblinded annotations are still stored — they are just reported separately and are not the reference set.

Why label blind

A model can propose a label for every span in seconds, which is the only way past the annotation bottleneck. But an analyst shown the proposal before judging will agree with it more often, and that agreement is not evidence the proposal was right — it is evidence the analyst was anchored.

So the proposal stays hidden until you have labelled the span yourself, and whether it was hidden is stored with your label. Agreement is reported separately for blind and unblind labels and never pooled. Unblind labelling is still useful for triage; it is just not a measurement of the model.

Live conversation

Paste a conversation you are having in another tab. Everything that reads the text runs immediately — register, refusal signal, spans, and the one thing a campaign cannot show at all: how the register moves across turns as you push. A campaign is one prompt and one response per cell by construction.

Layer 0 does not run here unless a question matches a corpus prompt. An answer key is derived from parameters written down in advance, so a question typed into a chat window has none — and without an objective channel there is no capability axis, no decoupling plane, no twin delta and no tone-bias control. What you get is description. It is useful and it is not a measurement of the surface.

Live sessions

A session is a conversation an agent or app is having right now, accumulated turn by turn. The tool never reaches into another process: a source opts in by POSTing each turn to /api/session/turn as it happens — the paste boundary generalised, push, never pull. Everything the Live view does runs on each session, and its register trajectory updates as the agent keeps talking. Wiring one up is one HTTP call per turn; docs/INTEGRATION.md has the four modes and what each can and cannot measure.

Layer 1.5 — stance, posture and the decoupling

Stance, not emotion. A model has no affective state to chart; a text has a register, and that is decidable from the words on the page. Everything here counts markers, and every marker is meta-discursive — how the model talks about its answer, never what the answer is about. That is what makes the alarming-benign null control below a real test rather than a restatement of the question.
