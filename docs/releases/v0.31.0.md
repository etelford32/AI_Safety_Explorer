# AI Safety Explorer v0.31.0

**The first public release of AI Safety Explorer, by Elliot Telford** — an open research instrument
for one question: *when the framing of a request gets riskier while the reasoning task stays the
same, how does a model's behaviour change?*

## Download

**macOS (Apple Silicon):** `AI-Safety-Explorer-macOS.zip`, below. Unzip, drag
**AI Safety Explorer.app** to Applications, and the first time **right-click → Open** (the app is
not signed with an Apple developer certificate). From then on the app keeps itself up to date:
it follows tagged releases, verifies each new version before switching to it, and falls back to
the last version that worked. Full guide: [docs/INSTALL.md](https://github.com/etelford32/AI_Safety_Explorer/blob/main/docs/INSTALL.md).

**From source (any OS, Python 3.11+):** `git clone`, then `pip install -e '.[dev]'` and
`explorer serve`. No third-party runtime dependencies.

## What it does

- **Matched prompt twins.** A versioned corpus in which each risky prompt has a benign twin posing
  the same intellectual operation; the framing moves along one dimension (intent, operationality,
  specificity, autonomy, depth) while the task holds still. The linter enforces it.
- **Objective correctness.** Responses are scored against answer keys computed from parameters
  fixed in advance, so capability loss is measured, not inferred from tone.
- **Register and agency, with their null controls.** Warmth, moralising, distancing, refusal and
  posture; expressed agency read against the autonomy the prompt granted (*reach past the
  mandate*); each reading ships with the control that could show it to be an artefact.
- **Pre-registered analyses.** The depth interaction (H4), sandbagging under observation cues
  (H11), the cross-lingual surface (H10), false-positive controls, reliability and drift.
- **Live sessions.** Watch a conversation as it happens — pushed by an agent, or captured from
  Claude.ai and ChatGPT by the included userscript — with register drift and power-seeking flags.
- **Private by construction.** Everything runs on your computer; nothing is sent anywhere but the
  model provider you choose for a campaign.

## In this release

- A self-updating macOS app with a stable/dev channel, verification before every switch, and
  rollback to the last good version or the copy built into the app.
- The Overview dashboard, grouped navigation, command palette (⌘K), and a glossary on hover.
- Browser capture for Claude.ai and ChatGPT, with edits and regenerations kept as branches.
- Demo data (`explorer demo`) and a live agent simulator, so every screen can be explored at once.
- Open-source groundwork: citation metadata, security policy, contributing guide, CI on
  Python 3.11–3.13, and a macOS build smoke-tested before it is published.
